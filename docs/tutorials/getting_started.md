# Getting Started with smb-ops-ui

This tutorial guides you through setting up the frontend application for local development.

## Prerequisites

* Node.js 20+
* pnpm 9+

## Step 1: Install Dependencies

```bash
pnpm install
```

## Step 2: Start Development Server

```bash
pnpm run dev
```

Visit the running application at `http://localhost:5173`.
